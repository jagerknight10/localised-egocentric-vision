Abstract

Localized Egocentric Vision studies causal action recognition from a compact, task-relevant visual stream. Rather than processing every pixel of the full egocentric frame at every moment, the approach dynamically allocates visual attention to the hand–object regions that matter for the ongoing task. This localized stream reduces the effective context space while retaining the temporal transitions needed to distinguish and define actions. At each moment, recognition is based only on visual evidence available up to that time.

Localized causal stream

Each egocentric frame is reduced to the hand–object region that is relevant to the ongoing task. This localized crop carries the visual evidence for the current action while discarding the surrounding scene, so the model reasons over a compact visual history rather than full frames.

Action boundaries are defined by temporal transitions: one action ends and another begins when the localized evidence changes. Because the stream is causal, the representation at any moment contains only past and current observations — the future is not available, mirroring the setting in which a system must recognize an action while it is still unfolding.

Demo video, bounding boxes, and action labels use the GTEA dataset (Li, Liu & Rehg, “In the Eye of the Beholder: Joint Learning of Gaze and Actions in First Person Video,” ECCV 2018). Boxes and crops derive from its hand-mask annotations; all on-screen labels are dataset annotations, not model predictions.

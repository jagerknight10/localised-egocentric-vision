Localized Egocentric Vision

Efficient causal action recognition from relevant visual context

Abstract

We study causal action recognition in egocentric videos: can a model use only visual evidence available up to the current moment to recognize an ongoing action? The project compares a frame-level linear baseline with a causal Transformer that receives a history of frozen DINOv2 visual features. It also evaluates an oracle restricted-input condition, where a hand-region annotation localizes the hand–object interaction before visual encoding. Across leave-one-subject-out pilot experiments on EGTEA, temporal context improves both macro accuracy and balanced accuracy over frame-level recognition.

Method

Video frames are sampled deterministically every 15 frames. A frozen DINOv2-small encoder maps each sampled image to a cached 384-dimensional feature vector. The evaluated models receive the same features, labels, and subject-level split; only their temporal access differs.

Temporal context improves the pilot metrics. Macro accuracy increases from 72.2% to 85.0% (+12.8 percentage points), while balanced accuracy increases from 50.3% to 70.6% (+20.3 percentage points).

Localized visual input

Using the same clips, labels, splits, and causal Transformer, the oracle hand-restricted representation obtains a macro mean accuracy of 79.9%, compared with 78.3% for its paired full-frame representation. This suggests that much of the visual field may be unnecessary for these hand–object actions, motivating relevance-aware visual encoders.

Limitations and scope

  • The restricted-input condition uses hand annotations as oracle inputs; it is not an automatic hand detector.
  • Results are pilot results from four held-out-subject runs and should not be read as a general benchmark claim.
  • The video is a project overview, not redistributed EGTEA footage or a clip-level inference visualization.

Implementation and reproducibility details are available in the GitHub repository.
